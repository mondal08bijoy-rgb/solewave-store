# SOLEWAVE — Full-stack sneaker store demo

## Run locally
1. Install Node.js 18+.
2. Extract the ZIP and open a terminal in this folder.
3. Run `npm start` (or `node server.js`).
4. Visit `http://localhost:3000`.

## Pages
Home `/` · Shop `/shop.html` · Product `/product.html?id=sw-001` · Cart `/cart.html` · Checkout `/checkout.html` · Our Story `/about.html` · Contact `/contact.html` · Admin `/admin.html`.

## Features
Product catalogue API, category filtering, search, sorting, size selection, interactive cart saved in localStorage, backend order creation, JSON order storage, admin order listing and status updates.

## Stack
HTML/CSS/vanilla JS frontend, Node.js built-in HTTP backend, JSON file data store. No external npm dependencies.

## Demo limitations
No real payment, courier, email or admin authentication. Add authentication, a proper database, validation, rate limiting and HTTPS before production use.
